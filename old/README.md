# Старая версия (Qt/C++ + Python)

Архив исходной реализации AnimeDL, которую заменяет новый Node.js/Electron/React
проект в корне репозитория. Оставлена как справочная реализация логики
(поиск/эпизоды/источники/качества/скачивание) на время переноса — см. план и
список задач в `../README.md`.

Сборка не поддерживается из этого расположения (CI, CMake-пути и `.github/workflows`
были рассчитаны на корень репозитория).
